# Graph Data Structure & Coloring Algorithms

A Java application built to create graphs, load them from files, and color them.
It handles nodes, edges, connections between points, and display settings like colors and sizes.
The program includes three coloring methods: Welsh-Powell, 6-coloring, and recursive 5-coloring for planar graphs.
It reads graph files automatically and comes with custom JUnit tests to verify graph updates and node colors.
